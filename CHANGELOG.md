# Change Log

All notable changes to the "penumbra" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [2.1.1]

- Add merge conflict, debugger (`debugIcon.*`, stack frame highlights), and test explorer (`testing.icon*`) UI colors
- Add `decorator` and `*.deprecated` strikethrough LSP semantic token rules
- Add TextMate scopes for `markup.strikethrough`, `constant.character`, `support.constant`, directives, and annotations

## [2.1.0]

- Lift `sky` and re-anchor the daylight curve for `Contrast+` and `Contrast++` dark themes alongside recalculated dark accent palettes
- Switch syntax highlighting and extension icon to the 8-colour accent palette with polygon chroma maximization
- Use the equidistant 6-colour palette for `terminal.ansi*` and map `ansiWhite`/`ansiBrightWhite` to `sun`/`sun+`

## [2.0.0]

- Full v2 overhaul using Revised CAM16-UCS with Helmholtz–Kohlrausch brightness compensation
- Contrast-symmetric dark and light workbench UI hierarchy and full LSP semantic token support

## [1.0.0]

- Fix contrast of active list selection foreground across dark and light themes
- Final legacy Oklab release

## [0.4.0]

- Scrollbar in the Light version now has the proper, darker color

## [0.3.0]

- Terminal curser no longer invisible, now has the properly inverted color

## [0.1.0]

- Initial release
